ComfyUI Mobile Studio · 算力节点部署包
=====================================

这是由主机生成的部署包，不包含模型权重、账号密码或 worker secret。

一、准备
--------
1. 解压到一个普通文件夹。
2. 目标机器已安装 ComfyUI（便携版），并且能启动。
3. 把主机上的模型按相同目录结构复制到目标机器：
   ComfyUI\models\checkpoints、diffusion_models、text_encoders、vae、loras、
   upscale_models 等。
4. 自定义节点也建议与主机保持一致。

二、检测环境
------------
双击“仅检测环境.bat”。
脚本会自动寻找 ComfyUI；找不到时会让你输入目录。
检测结束后会打开一个和主程序同风格的 HTML 报告，列出：
- 缺少的模型
- 大小不一致的模型
- 缺少的自定义节点目录
- ComfyUI 版本差异

三、接入中央
------------
1. 在中央网页“后台 → 算力节点”生成 8 位接入码。
2. 双击“部署并启动.bat”。
3. 按提示确认中央地址、输入接入码和节点名称。
4. 脚本会写入 worker_agent.json，启动 worker，并打开本机控制页：
   http://127.0.0.1:8199/

四、注意
--------
- 模型不会自动复制；检测报告会告诉你缺什么。
- 中央地址默认是主机生成时的热点地址，例如 https://192.168.137.1:8800。
- 部署包里的 cert.pem 是公开证书，不包含私钥。
- worker_agent.json 包含节点 secret，不要复制给其他机器。
- 不要把部署包或 worker_agent.json 发给无关人员。
