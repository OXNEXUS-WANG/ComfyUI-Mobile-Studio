# 局域网算力节点（worker）

这个文件夹复制到另一台 Windows 机器，就能把它的 ComfyUI 算力借给中央的
「手机出图」网页。节点只主动连接中央，**不需要在 worker 上开放局域网端口**。

## 先决条件

- 这台机器和中央电脑连在同一个 Windows 热点（中央通常是 `192.168.137.1`）。
- 这台机器已经装好 ComfyUI，并能正常在本机 `http://127.0.0.1:8188` 出图。
- 模型和自定义节点要和中央保持一致：
  - 底模、LoRA、VAE、文本编码器、放大模型按原文件名复制到对应目录；
  - 中文提示词建议让中央预翻译；如果中央翻译失败，worker 还需要
    `AlekPet` 的 `ArgosTranslateTextNode` 和语言包。
- 不要把 `worker_agent.json` 复制到另一台机器同时运行；每台机器用自己的接入码。

## 0. 推荐：用主机生成的部署包

管理员在中央「后台 → 算力节点 → 生成节点部署包」下载 ZIP，解压到这台机器：

1. 双击 `仅检测环境.bat`，查看模型/节点差异报告；
2. 按报告补齐模型和自定义节点；
3. 双击 `部署并启动.bat`，输入接入码，自动写入配置并启动 worker。

部署包不会包含模型、账号密码或 secret。

## 1. 盘点本机

先启动 ComfyUI，然后双击：

```
盘点本机算力.bat
```

会打印 GPU、显存、ComfyUI 版本、模型清单和节点数量。确认能看到这台机器的
ComfyUI 和模型，再继续。

## 2. 接入中央

1. 管理员在中央网页「后台 → 算力节点 → 生成接入码」生成 8 位接入码。
2. 把中央的 `cert.pem` 复制到本文件夹（推荐），然后双击：

```
接入算力节点.bat
```

输入接入码和节点名称。也可以手动运行：

```
python worker_agent.py join --server https://192.168.137.1:8800 ^
  --code 你的接入码 --name "客厅电脑" --ca cert.pem
```

如果暂时没有 `cert.pem`，可以只用一次 `--insecure`（热点内临时回退，
不推荐长期使用）。

## 3. 管理员审批

回到中央网页「后台 → 算力节点」，找到待审批节点：

- 设置所有者（owner）；
- 打开“可信节点”（普通账号的提示词会发送到这台机器）；
- 勾选允许使用它的普通账号；
- 保存并批准。

节点会显示在线、GPU、模型清单。普通账号只有在“可信 + 白名单内”才能使用它；
管理员不受限。

## 4. 开始接单

```
启动算力节点.bat
```

浏览器打开 `http://127.0.0.1:8199/` 可以看到本机控制页：

- 暂停接单：不再接新任务，当前任务跑完；
- 恢复接单；
- 查看当前任务和上次错误。

也可以双击 `暂停接单.bat` / `恢复接单.bat`。

## 5. 模型不一致

中央后台的节点卡片会显示“缺模型：N 个”。把对应文件复制到这台机器的
`ComfyUI/models/...`，然后在卡片上点“刷新清单”，或重启节点程序。

任务只会派给模型齐全、节点类齐全的 worker；缺模型不会强行派过去。

## 安全说明

- worker 只主动连中央 HTTPS 8800；不监听局域网端口。
- 中央只接受本机或 `192.168.137.0/24` 的 worker，校园网 `172.24.x` 会被拒绝。
- 执行任务时，worker 本机能在 ComfyUI 工作流里看到提示词；所以只把
  “可信”开关打开给你信任的机器。
- 不要把接入码、`worker_agent.json` 或 `cert.pem` 发给别人。
- 任务结束会尽量清理 worker 本机的临时输入/输出；如果 ComfyUI 路径无法推导，
  可能需要手动清理 `ComfyUI/input/_worker_*`。

## 常见问题

- **控制页打不开**：节点程序没启动，或 8199 被别的程序占用。
- **连不上中央**：确认在热点网段、中央服务已启动、地址是 `192.168.137.1:8800`。
- **证书错误**：复制中央的 `cert.pem`，或临时 `--insecure`。
- **一直待审批**：管理员还没在后台批准。
- **一直未就绪**：本机 ComfyUI 没启动，或 `/system_stats` 不通。
- **模型缺失**：按后台缺模型列表复制文件并刷新清单。
- **当前只支持图片任务**：文生图、图生图、局部重绘；放大/视频仍在本机执行。
