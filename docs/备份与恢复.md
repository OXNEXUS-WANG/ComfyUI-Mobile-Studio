# 备份、恢复与磁盘保护

> 适用：CometInk v1.3.17
>
> 内网自用最怕两件事：**图库/账号所在磁盘满了写不进去**，以及**换机器/重装时
> 图库和账号没备份**。日志是否防篡改不是第一优先级。

---

## 1. 默认备份什么

`备份数据.bat` → `tools/backup.py`，默认备份：

- `users.json`（账号和密码哈希）
- 账号限额、用量统计、worker/节点、团队、翻译、监控、清理、队列、守护配置
- 图库的元数据（`.json`），不包含图片本体
- 工作流 JSON、插件注册表和安全插件包
- 可选：活动/安全日志（`--logs`）
- 可选：图库图片/视频（`--images`）

**不包含**：模型文件、ComfyUI 本体、Python 环境、证书（证书单独备份）。

---

## 2. 一键备份

双击：

```text
备份数据.bat
```

生成的 ZIP 在安装目录的 `_backups\backup-YYYYMMDD-HHMMSS.zip`。

连图片一起备份（文件会大很多）：

```powershell
python tools\backup.py --images
```

连日志一起：

```powershell
python tools\backup.py --images --logs
```

指定输出位置：

```powershell
python tools\backup.py --images --out D:\Backups\cometink-20261023.zip
```

> 备份 ZIP 里有账号密码哈希和 worker secret 哈希，请像密码文件一样保管，
> 不要发群、不要上传网盘公开链接。

---

## 3. 恢复

**先停服务**，再双击：

```text
恢复数据.bat
```

或命令行：

```powershell
python tools\restore.py _backups\backup-20261023-120000.zip --yes
```

恢复工具会：

1. 校验 ZIP 和 manifest；
2. 先把当前状态备份到 `_backups\pre-restore-*.zip`；
3. 覆盖账号、配置、图库元数据/图片（如果备份里有）；
4. 提示重启服务。

恢复后：

- `sessions.json` 如果没备份，所有人需要重新登录；
- 证书如果没备份，手机需要重新信任新证书；
- 图库缩略图会按需重建，第一次打开可能稍慢。

---

## 4. 建议的备份节奏

| 场景 | 建议 |
|---|---|
| 个人自用 | 每周备份一次元数据；出图多的月份加 `--images` |
| 小团队 | 每天备份元数据；每周完整图片备份到另一块盘 |
| 改账号/限额/模型前 | 先创建还原点或手动备份 |
| 换电脑/重装前 | `--images --logs` 完整备份 + 单独复制 `cert.pem` / `key.pem` |

至少保留两份，其中一份在另一块物理磁盘或移动硬盘上。

## 5. 磁盘阈值与自动清理

配置文件：`cleanup.json`（管理后台「自动磁盘清理」也可改）。

| 键 | 默认 | 说明 |
|---|---|---|
| `warn_free_gb` | 10 | 低于此值健康报告/告警提示 |
| `critical_free_gb` | 1 | 低于此值**暂停新出图/上传**（507） |
| `min_free_gb` | 10 | 低于此值触发自动清理（需开启） |
| `target_free_gb` | 20 | 自动清理到此值以上 |
| `retention_days` | 30 | 只清理超过这么多天的文件 |
| `max_files_per_run` | 500 | 单次最多删除数量 |
| `include_videos` | true | 是否包含视频 |
| `include_comfy_output` | false | 是否清理 ComfyUI/output 原始输出 |

重要原则：

- **不会自动删除用户图片**，除非你主动开启自动清理；
- 自动清理只处理超过保留天数的文件，**收藏永远保留**；
- 磁盘低于 `critical_free_gb` 时，服务会拒绝新任务/上传，但不会崩溃，
  已有任务可以继续跑完；
- 磁盘满了先清理 `generated/.archives/`、旧日志、ComfyUI/output，
  再考虑扩容；不要直接删 `users.json` 或 `sessions.json`。

---

## 6. 日志轮转

- 每天一个文件：`logs/activity-YYYY-MM-DD.jsonl`、
  `logs/security-YYYY-MM-DD.jsonl`；
- 默认保留 30 天，每小时清理过期文件；
- 日志不记录提示词正文、图片文件名、密码、API Key；
- 需要长期留存时，用 `python tools\backup.py --logs` 归档，不要只依赖本机日志。

## 7. 恢复演练

建议每学期/每季度做一次：

1. 在一台干净机器（或临时目录）安装同版本；
2. 停服务；
3. 用备份 ZIP 恢复；
4. 启动服务，确认能登录、图库能看到图、限额还在；
5. 删除演练环境。

只有真正恢复过一次，备份才算可用。
