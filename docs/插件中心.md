# 插件中心

插件中心分两层：**安全插件包**和 **ComfyUI 代码插件**。前者不执行代码，普通账号可直接导入；
后者会进入 ComfyUI 进程，必须经过管理员审批，并且只动 `ComfyUI/custom_nodes`，不会改网页程序、
账号、图库、证书和模型。

## 一、安全插件包（JSON，普通账号可用）

安全插件包只包含三类内容：

- `styles`：画风名称 + 中文后缀，会出现在「画风」条里；
- `prompts`：提示词模板，点一下填入提示词框；
- `presets`：画幅、步数、CFG、张数预设，点一下套用参数。

它不包含 Python、JS、HTML、网络地址或文件路径，服务端只做 JSON 校验和存储，**不会执行任何代码**。
插件包只影响导入它的账号，不会自动共享给其他账号。

### 示例

```json
{
  "schema": 1,
  "name": "我的国漫风格包",
  "id": "my-manhua-pack",
  "version": "1.0.0",
  "author": "你的名字",
  "description": "低饱和国漫风格和几个快速预设",
  "styles": [
    {"name": "淡彩", "suffix": "国漫淡彩，低饱和度，柔和光线，干净线条"}
  ],
  "prompts": [
    {"name": "雨夜少女", "text": "杰作，最高画质，雨夜的青石巷，少女撑伞回头"}
  ],
  "presets": [
    {"name": "快速草图", "size": "512x512", "steps": 8, "cfg": 4, "count": 1}
  ]
}
```

限制：

- 单文件 ≤ 256KB，每个账号最多 20 个包；
- 最多 20 个风格、50 条提示词、20 个预设；
- 画幅 16~1536 像素、必须是 16 的倍数；
- 步数 1~60、CFG 0~20、张数 1~4；真正出图时仍受账号限额约束；
- 超过模型上限的画幅会在出图时自动等比缩小。

入口：主页面「插 件」标签 →「我的插件包」→ 选择 JSON →「导入插件包」。
导入后可以停用/启用/删除；删除只删当前账号的插件包。

## 二、ComfyUI 代码插件（需要管理员审批）

普通账号可以在「代码插件」区提交 ZIP，但**提交只写入隔离区，不会安装、不会导入、不会执行**。

### 提交限制

- ZIP ≤ 20MB，解压后 ≤ 80MB，文件数 ≤ 2000；
- 不接受加密 ZIP、路径穿越、绝对路径、符号链接、exe/dll/so/pyd/bat 等危险文件；
- 必须有 `__init__.py`，并包含 `NODE_CLASS_MAPPINGS` 或 `WEB_DIRECTORY`；
- 每个账号最多 3 个待审批提交，全局隔离区最多 40 个 / 500MB；
- 提交后进入 `plugins/quarantine/<提交编号>/payload.zip`，静态扫描只读文本，不运行插件代码。

### 静态风险扫描

会提示以下调用（只是提示，不是沙箱，也不能代替代码审计）：

- 高风险：`subprocess`、`os.system`、`os.popen`、`eval`/`exec`、`ctypes`、`torch.load`、
  读取账号/证书文件、注册表/计划任务；
- 中风险：网络访问、删除文件、修改 `sys.path`；
- 低风险：没有发现上述调用。

高风险插件必须由管理员显式勾选「强制批准」才会安装。

### 审批、禁用与回滚

管理员在「插件中心 → 管理员审批」里可以：

- **批准安装**：同名插件默认拒绝覆盖；确认覆盖时先把旧版本复制到
  `plugins/backups/<插件名>/<时间>/node`，最多保留 3 份；
- **拒绝**：填写原因，原始 ZIP 立即清理；
- **禁用**：把插件目录移到 `plugins/disabled/`，不再被 ComfyUI 加载；
- **启用**：从禁用目录移回 `custom_nodes`；
- **回滚**：用最近一次备份恢复，当前版本移到 `plugins/disabled/`；
- **校验**：重新计算目录哈希，发现插件被外部改动会标为「文件被改动」；
- **移除**：移到 `_node_trash`，不会直接删除；
- **禁用全部第三方插件**：只处理插件中心管理的插件，不碰预装节点。

安装、禁用、启用、回滚后需要**重启 ComfyUI** 才会生效；网页会显示提示，
重启完成后管理员点「已重启 ComfyUI」清除提示。网页服务本身不依赖 ComfyUI，
即使插件导致 ComfyUI 起不来，仍然可以打开插件中心禁用/回滚。

### 预装节点保护

首次启动时，`ComfyUI/custom_nodes` 里已有的目录会被记为 `baseline`，插件中心不会自动修改它们。
通过旧「后台 → 自定义节点」导入的节点会被纳入插件中心管理，可以使用禁用/回滚等操作。

## 三、权限与审计

新增两个账号功能开关（管理员在「后台 → 账号管理 → 功能开关」里设置）：

| 开关 | 默认 | 作用 |
|---|---|---|
| 安装安全插件 | 开 | 允许导入/启停/删除自己的 JSON 插件包 |
| 提交代码插件 | 开 | 允许提交代码插件 ZIP 到隔离区；安装仍需管理员审批 |

游客默认关闭。管理员始终允许。关闭后接口返回 403，并写安全日志。

所有提交、批准、拒绝、禁用、启用、回滚、删除都会写入安全日志；日志只记录插件名/提交编号、
大小、风险等级和操作者，不记录插件源码或提示词正文。

## 四、数据位置

| 内容 | 位置 |
|---|---|
| 安全插件包 | `plugins/packs/<账号>/<插件包 ID>.json` |
| 待审批 ZIP | `plugins/quarantine/<提交编号>/payload.zip` |
| 安装前备份 | `plugins/backups/<插件名>/<时间>/node/` |
| 禁用目录 | `plugins/disabled/` |
| 注册表 | `plugins/registry.json` |
| 真正安装位置 | `ComfyUI/custom_nodes/<插件名>/` |
| 删除回收站 | `_node_trash/` |

`plugins/` 已加入 `.gitignore` 和发布包排除列表；备份工具只备份注册表和安全插件包，
不备份隔离区 ZIP 和节点备份。

## 五、边界说明（必须知道）

- ComfyUI 自定义节点是 **Python 代码**，最终运行在 ComfyUI 进程里，和 ComfyUI 拥有同样的
  文件、网络和进程权限。审批只是管理流程，**不是操作系统级沙箱**。
- 静态扫描只能发现明显的危险调用，不能证明插件安全；不要批准来源不明的代码。
- 插件能看到它被执行时的工作流和提示词；不要把不可信插件用在敏感提示词上。
- 插件只能通过 ComfyUI 节点图使用；当前网页的固定出图按钮不会自动调用新节点。
- 任何插件变更都只动 `custom_nodes`，不会修改 `app_core.py`、`web_server.py`、
  `users.json`、`cert.pem` 或图库。
