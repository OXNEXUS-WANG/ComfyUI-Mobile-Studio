## 2. 模型实际下载（18MB 放大模型）

测试对象：`amd/realesrgan-x4plus-anime-6b/RealESRGAN_x4plus_anime_6B.pth`
（固定 revision，期望 17,938,799 字节）

| 场景 | 结果 | 耗时 / 说明 |
|---|---|---|
| 首次下载 | 失败（预期外） | hf-mirror 返回 **HTTP 429 Too Many Requests**；直连 huggingface.co 超时 |
| 重新运行 | 通过 | 17,938,799 字节，约 28.6 秒，大小校验通过 |
| 断点续传 | 通过 | 从 5MB `.part` 继续，约 12.6 秒，最终大小精确 |
| 已存在完整文件 | 通过 | 直接 `[跳过]`，不重复下载 |
| 错误大小的旧文件 | 通过 | 检测到大小不符后删除并重新下载，约 5.8 秒 |

首次 429 暴露了原下载器“一次限流就换源/失败”的问题。已修复：

- `download_models.py` 对 **429 / 500 / 502 / 503 / 504** 自动重试同一镜像；
- 优先读取 `Retry-After`，否则按 3/6/9 秒退避，单镜像最多 3 次；
- 重试期间保留 `.part`，继续断点续传；
- 404 等不可重试错误直接换下一个镜像。

新增 `tests/test_download_models.py`，用本地 mock HTTP 覆盖：429 后重试成功、
`.part` 续传、大小不符替换、完整文件跳过，共 4 项。
