# 手机出图网页 · 提示词合集

这份文档记录了从一个空文件夹到「手机出图网页」的完整提示词。
可以直接发给 AI（Claude / GPT 等）照着做。

> **前提**：Windows + NVIDIA 显卡 + 已装好 ComfyUI，浏览器能打开
> `http://127.0.0.1:8188` 并正常出图。本机 8GB 显存、16GB 内存。
>
> 如果连 ComfyUI 都还没有，先做「阶段 0」。

---

## 一、一次性总提示词（懒人版）

> 直接整段复制。缺点是一次生成 5000 行，AI 容易漏细节；
> 想稳一点用下面的「分阶段版」。

```
你是一个 Python 全栈工程师。帮我做一个**单文件的手机出图网页服务**，
跑在我自己的 Windows 电脑上，后台调用本机 ComfyUI。

## 环境
- ComfyUI 在 http://127.0.0.1:8188，主模型 Illustrious-XL-v2.0（SDXL 系二次元）
- 显卡 8GB 显存，内存 16GB
- 手机通过 Windows 移动热点连电脑（热点网关固定 192.168.137.1）

## 技术约束（重要）
- 只写一个 mobile_web.py，用标准库 http.server.ThreadingHTTPServer 起服务
- 不要 Flask / FastAPI / npm / 前端构建工具
- 图片处理用 Pillow
- 前端 HTML/CSS/JS 全部内嵌在这个 .py 里

## 功能
1. 文生图：手机输中文 → POST /prompt → 轮询 /history → 图片回显
2. 图生图 + 局部重绘（上传参考图和蒙版）
3. 图库：缩略图网格、搜索、收藏、多选删除、全屏查看、左右滑动
4. 参数：尺寸、张数、步数、CFG、种子（可锁定复现）、LoRA、高清修复
5. 实时进度：WebSocket 连 ComfyUI 的 /ws 拿步数和中间预览图
6. 参考图超过 1.3 百万像素时自动等比缩小（8GB 显存直接跑会爆）
7. 中文提示词自动翻译成英文（在 ComfyUI 工作流里挂 Argos 翻译节点）
8. 缩略图本地缓存，避免每次都读原图
9. 访问密码 + 会话 cookie
10. 只监听 127.0.0.1 和热点网卡，绝不对公网开放

## UI
- 深色玻璃拟态 + 深空渐变背景
- 手机竖屏优先；宽屏 ≥900px 自动变成「左侧控制栏 + 右侧预览」
- 有入场动画、选中回弹、进度条流光
- 尊重系统「减少动态效果」设置
- 科技感：网格底纹、HUD 四角标记、青色发光、等宽数字

## 输出
完整的 mobile_web.py，直接 python mobile_web.py 就能跑。
```

## 二、分阶段提示词（推荐）

### 阶段 0：先把 ComfyUI 跑起来

```
帮我在这台 Windows 电脑上装一个能出二次元图的 ComfyUI 环境。
配置：RTX 5060 Laptop 8GB 显存 + 16GB 内存。

要求：
1. 用便携版（自带 Python，不污染系统环境）
2. PyTorch 必须支持 Blackwell 架构 sm_120，否则会报 no kernel image available
3. 主模型用 SDXL 系的二次元模型（Illustrious 或 NoobAI）
4. 装 VAE 修正模型、动漫 4 倍放大模型
5. 配好 ComfyUI-Manager，并解决国内网络访问问题
6. 桌面建一个启动快捷方式
```

> 国内网络补充一句：`huggingface.co` 和 `github.com` 直连很慢，
> 用 `hf-mirror.com` 和 `gh-proxy.com` 前缀代理。

### 阶段 1：最小可用版

```
写一个 Python 脚本 mobile_web.py，起一个网页服务，让手机能出图。

要求：
- 只用标准库 + Pillow
- 手机和电脑连同一个热点，手机浏览器打开 http://192.168.137.1:8800
- 页面包含：一个中文提示词输入框、尺寸选择（竖/横/方）、一个「出图」按钮
- 后台把提示词和参数拼成 ComfyUI 的 /prompt 工作流提交，轮询 /history/{id}
- 图出来了直接显示在页面上
- 中文提示词必须在 ComfyUI 工作流里挂 ArgosTranslateTextNode 翻译成英文，
  因为模型只认英文标签，纯中文会出纯噪声图
```

---

### 阶段 2：图生图 / 局部重绘

```
给网页加上图生图和局部重绘。

- 图生图：上传参考图，按参考图重新生成，带 denoise 滑块
- 局部重绘：在图上涂一块，只重画涂到的地方（蒙版白色区域重画）
- 画幅由参考图决定
- **重要**：8GB 显存下参考图超过约 1.3 百万像素会直接卡死。
  超过时在编码前用 ImageScaleToTotalPixels 等比缩小，比例不能变
- 蒙版缩放要用 nearest-exact，否则边界会糊成灰边
```

---

### 阶段 3：UI 重写

```
把网页 UI 整个重写一遍，要好看、好用。

美术风格：深空玻璃拟态（glassmorphism）
- 深色背景 + 缓慢漂移的柔和光晕
- 卡片用半透明 + backdrop-filter 毛玻璃
- 圆角、细边框、柔和阴影

交互逻辑也一起改：
1. 出图时实时显示进度条和步数
2. 图库按时间倒序，支持搜索提示词
3. 参数面板收进「更多」里，主界面保持清爽
4. 出图后自动刷新图库
```

---

### 阶段 4：加动画

```
给界面加动效，但不要浮夸：
- 首屏分层入场（标题 → 标签页 → 输入框 → 按钮依次淡入上移）
- 按钮点按有轻微缩放反馈
- 选中项回弹
- 进度条有流光
- 出图结果揭示动画
- 必须尊重系统「减少动态效果」设置

注意：给 .view 这类容器加 transform 动画会创建 containing block，
导致里面 position:fixed 的吸底按钮失效。这种情况只能用 opacity 动画。
```

### 阶段 5：宽屏改左栏

```
宽屏（≥900px）时把控件从顶部移到左侧：
- 左边固定 410px 放提示词、参数、按钮
- 右边是出图结果 / 图库
- 吸底按钮和进度条也要收进左栏宽度，不能横跨整屏
- 手机上保持原来的单栏布局
```

### 阶段 6：随机提示词

```
加一个「随机灵感」功能：
- 按种类分类：人物 / 风景 / 动物 / 机甲 / 幻想 / 日常
- 每个种类有主体、发型、服装、动作、表情、细节、氛围等字段
- 可以多选种类，显示当前范围能组合出多少种
- 生成时随机抽取字段拼成中文提示词
- 再配一个「提示词生成器」：让用户手动勾选主体+场景+光线+画质+氛围
```

### 阶段 7：图片显示修整

```
两个显示问题修一下：
1. 出图后的图片太大，不能完整显示在左侧栏里
   -> 用 max-width:100% + max-height:76vh，宽屏下 max-height: calc(100vh - 200px)
2. 电脑端风格选项那一行显示不全，横向滚动条又看不见，鼠标也滚不动
   -> 宽屏下改成 flex-wrap: wrap，别用横向滚动
```

### 阶段 8：加功能（LoRA / 高清修复 / 提速）

```
继续加功能：
1. LoRA 支持：能选 loras 目录里的文件，带强度滑块，支持叠加多个
2. 高清修复（做成可选开关）：出图后 latent 放大 1.3 倍再低重绘率采样一遍
   - 高清修复的第一次实现用 VAEDecodeTiled，结果有拼块条纹
   - 改成普通 VAEDecode，denoise 提到 0.55，步数至少 16
3. 降步数提速：先实测 28 步 vs 20 步的耗时和画质差异再给建议
4. 种子锁定：能固定种子复现同一张图
```

### 阶段 9：提示词优化（效果见仁见智）

```
优化提示词处理，有时候输入的内容没有体现在图片上。

方案：服务端先按内置词表把中文转成 danbooru 标签（比如「双马尾」-> twintails），
词表覆盖不到的残句再交给 Argos 翻译，最后补上质量词并过滤 blurry 这类毁图词。

注意：这个方案技术指标更好（标签更准、少 10 秒），但实测画面会偏油腻、
被拉向模型默认审美。**做成一个开关，方便随时回退。**
```

> 我自己的结论：最后回退成了单纯的 Argos 机翻。你可以两种都试一下再决定。

### 阶段 10：访问密码

```
给网页加访问密码，但服务仍然只对热点开放，不要暴露到校园网。

要求：
- 密码用 PBKDF2-SHA256 存哈希，不存明文
- 登录后发 HttpOnly + SameSite=Strict 的会话 cookie，30 天有效
- 所有接口（除登录/退出）都要求登录
- 同一 IP 连错 5 次锁 10 分钟
- 未登录的 POST 连 body 都不读，直接 401
- 请求体大小设上限
- 配一个 安全设置.bat，让用户能设/改/取消密码
```

### 阶段 12：自审安全

```
把这个服务当成对外暴露的服务审一遍安全问题。

重点检查：
- 路径穿越（../、%2F、%5C、编码的点）

```

## 三、这些坑要提前告诉 AI

1. **Windows 的 `SO_REUSEADDR` 允许两个进程绑同一端口**
   第二个实例不会报错，会悄悄绑到别的地址，变成两个服务、会话不互通。
   单实例检测不能靠「bind 失败」，要主动探一下 `/api/session`。

2. **`.bat` 文件必须是纯 ASCII**
   带中文注释会让 cmd 按 GBK 解析乱套，报 `'ho' 不是内部或外部命令`。
   要在窗口里显示中文，让 Python 用 `SetConsoleTitleW` 或直接 print。

3. **ComfyUI 会把提示词写进 PNG 元数据**
   tEXt 块里有完整的 prompt 和 workflow。要分享图片的话，
   复制到交付目录时把 `prompt` / `workflow` 块剥掉（不动像素，只删文本块）。

4. **8GB 显存很紧**
   832×1216 / 20 步大约 6.6GB。出图前关掉浏览器和游戏。
   参考图超过 1.3MP 必须缩小，否则直接卡死。

5. **`backdrop-filter` + 全屏动画 = 卡**
   毛玻璃面板下面的任何动画都会触发每帧重算模糊。

6. **CSS `transform` / `filter` 会创建 containing block**
   祖先一旦有 transform，里面的 `position: fixed` 就失效了。

7. **Argos 离线翻译要特殊配置**
   默认用 stanza 分词，要从被墙的域名下模型。设 `ARGOS_CHUNK_TYPE=MINISBD`
   并手动放好语言包才能离线跑。

8. **中文直接喂 CLIP = 纯噪声**
   必须翻译成英文，而且最好是 danbooru 标签风格。
