## 本轮发现并修复的问题

### 1. 商用包英文 `install.bat` 没有进入清洁模式
商用包里有中文 `安装.bat` 和英文 `install.bat`。原来只有中文入口带
`-CommercialClean`；英文入口会按分享版运行，可能下载模型并安装 GPL 自定义节点。

修复：
- 构建商用包时，`install.bat` 也替换为商业清洁入口；
- `install.ps1` 读取包根目录的 `EDITION`，发现 `commercial` 时强制
  `-CommercialClean`，即使直接运行 ps1 也不会误装。

### 2. 安装日志容易误解
首次初始化账号时，`ensure_users()` 会打印
“已创建初始管理员 admin / admin”，随后安装器才设置用户输入的密码。
实际登录密码是对的，但日志看起来像默认密码是 `admin`。

修复：设置 `MGS_ADMIN_PASSWORD` 时，日志改为
“安装收尾会设置你输入的密码”，不再打印 `admin / admin`。

## 本轮未覆盖的范围

以下需要另一台干净机器/虚拟机，不能在本机安全模拟：

- **完整全新安装**：从零下载 ComfyUI 便携版（约 2GB）和默认模型（约 6GB）。
  本轮只验证了所有下载 URL 的 HEAD 检查，以及“复用已有 ComfyUI”的实际安装；
  没有真的下载 2GB+6GB 数据。
- **Windows 10 实机**：脚本使用 PowerShell 5.1，目标写的是 Windows 10/11，
  但本轮只在 Windows 11 上运行。
- **非中文 Windows**：中文和空格路径已测，但没有测英文/其他区域设置系统。
- **非管理员防火墙步骤**：当前就是非管理员运行，安装成功并提示手动运行
  `修复手机访问.bat`；没有以管理员身份再验证自动放行。
- **Linux / macOS**：安装器只支持 Windows，未测试也不支持。
- **商用版真实授权码激活**：激活页和未激活拦截已验证；本轮没有重新签发授权码。
- **ComfyUI 目录是 junction/符号链接**：这种人工测试方式下，模型下载器的路径
  越界检查会拒绝；真实安装使用普通目录不受影响。

## 结论

分享版和商用版的安装器在 Windows 11、非管理员、中文+空格路径、复用已有
ComfyUI 的场景下可以正常安装、启动、登录和出图；安装失败场景能明确报错，
不会破坏已有目录。

商用包本次修复了英文入口的清洁模式漏洞，建议在正式发布前再用一台干净
Windows 10/11 虚拟机跑一次完整“从零下载”安装。
