# 手机 HTTPS 访问与自签证书信任

> 适用：CometInk v1.3.15
>
> 服务只监听本机和热点网关，地址通常是 `https://192.168.137.1:8800`。
> 自签证书没有公共 CA 签名，所以手机第一次打开一定会提示“不安全”。
> 这是正常现象，**只在你自己的电脑/热点上点继续**。

---

## 1. 先确认三件事

1. Windows 的「移动热点」已经打开；
2. 手机连的是这个热点，不是校园网或家里 Wi-Fi；
3. 电脑上的 CometInk 服务窗口还开着，地址栏是 `https://` 而不是 `http://`。

如果手机打不开，先在电脑上运行「修复手机访问.bat」放行 8800 端口。

---

## 2. Android Chrome

1. 地址栏输入 `https://192.168.137.1:8800`。
2. 出现「您的连接不是私密连接」时，点 **高级**。
3. 点 **继续前往 192.168.137.1（不安全）**。
4. 输入账号密码登录。

不同 Chrome 版本的按钮文字可能是「继续前往」或「仍然继续」，意思一样。

> 如果 Chrome 没有「继续前往」：
> - 换用 Edge / Firefox 手机版打开一次；
> - 或在「设置 → 安全 → 加密与凭据 → 安装证书」里安装自己的
>   `cert.pem`（只在自己的设备上装，不要装来源不明的证书）。

---

## 3. iPhone / iPad Safari

1. Safari 打开 `https://192.168.137.1:8800`。
2. 出现「此连接非私人连接」时，点 **显示详细信息**。
3. 点 **访问此网站**。
4. 再点一次 **访问网站** 确认。

如果要把证书装成受信任的描述文件（可选，步骤更多）：

1. 把 `cert.pem` 通过 AirDrop / 文件 App 传到手机；
2. 点开证书 → 允许下载描述文件；
3. 「设置 → 已下载描述文件」→ 安装；
4. 「设置 → 通用 → 关于本机 → 证书信任设置」→ 打开完全信任。

> 只有在你确认这是自己电脑生成的证书时才安装。换电脑、换 IP 后要重新生成，
> 旧证书不要继续信任。

---

## 4. 关于 HSTS

服务响应会带 `Strict-Transport-Security`，但 **浏览器对 IP 字面量会忽略 HSTS**。
所以：

- 不要对外说“HSTS 防劫持”；
- 真正的保护是：只在内网监听、HTTPS、`Secure` Cookie、手机手动信任；
- 如果以后用域名访问（例如 `cometink.lan`），HSTS 才有意义，并且需要
  受信任的证书或本地 CA。

---

## 5. 换 IP / 换机器

自签证书的 SAN 里写死了当前 IP。出现以下情况要重新生成：

- 换了热点网段；
- 换了电脑；
- 手机提示证书和地址不匹配。

操作：电脑上运行「安全设置.bat」→ 选 3 重新生成证书 → 重启服务 →
手机重新按上面的步骤信任一次。

---

## 6. 不要做的事

- 不要把 8800 端口映射到公网，不要用内网穿透/反向代理把服务暴露出去；
- 不要在公共 Wi-Fi、网吧、酒店网络里点“继续前往”；
- 不要把 `cert.pem` / `key.pem` 发给别人；
- 不要安装来源不明的“根证书”，那会让别人可以解密你的 HTTPS。
