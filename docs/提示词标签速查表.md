# 提示词标签速查表（中文对照）

**核心规则：提示词必须写英文，不是中文。**

Illustrious XL 的文本编码器是用英文 danbooru 标签训练的。
中文在它眼里是乱码——实测输入中文会直接输出纯噪声图，**比什么不写还差**。

好消息是：danbooru 标签就是一堆简单英文单词，常用的就那几百个。
照着这张表拼，不需要任何英文基础。

> 用法：从下面各个分类里挑词，**用英文逗号 + 空格**连接起来。
> 例如：`1girl, solo, long hair, blue eyes, school uniform, classroom, sunlight`

---

## 1. 质量词（固定带上，放最前面）

这几个词直接决定画面"精不精致"，建议每次都加上：

```
masterpiece, best quality, very aesthetic, absurdres
```

| 英文 | 中文 |
|---|---|
| `masterpiece` | 杰作 |
| `best quality` / `high quality` | 最高画质 |
| `very aesthetic` | 非常有美感 |
| `absurdres` | 超高分辨率（让画面更锐利） |
| `highres` | 高分辨率 |
| `newest` | 最新风格 |

## 13. 不想背单词？三个偷懒办法

1. **用 AI 帮你翻译成标签**
   直接跟我说"我要一个在雨里打伞的银发少女"，我帮你转成标签。
   这是最省事的方式，因为你描述中文，我翻标签。

2. **装提示词翻译插件**
   ComfyUI 里有把中文自动翻译成标签的节点，但**需要联网**（走在线翻译接口）。
   想装的话跟我说。

3. **记住高频的 30 个词就够了**
   实测日常出图 80% 的需求，用下面这些词就能覆盖：
   ```
   1girl, solo, long hair, short hair, black hair, white hair, blonde hair,
   blue eyes, red eyes, smile, blush, open mouth, looking at viewer,
   school uniform, dress, kimono, thighhighs,
   standing, sitting, arms behind back, hand on hip,
   classroom, bedroom, outdoor, night, sunset, sky, flowers,
   sunlight, depth of field, detailed background
   ```

## 14. 常见错误

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| `一个女孩，长头发` | 中文无效，出噪声图 | `1girl, long hair` |
| `a girl with long hair` | 自然语言句子，效果差 | `1girl, long hair` |
| `1girl 1boy` | 缺逗号，会被当成一个词 | `1girl, 1boy` |
| `masterpiece, best quality, 1girl, ...` 写在负面里 | 放错框了 | 质量词放**正面** |
| 提示词写了 300 个标签 | 超过 77 词会被截断，后面的无效 | 挑 15~30 个最关键的 |
