# ComfyUI 二次元出图环境 · 使用说明

为你这台 **RTX 5060 Laptop (8GB) + 16GB 内存** 的机器定制的配置。
安装位置：`D:\AI\ComfyUI_windows_portable`

---

## 零、快速上手（第一次看这里）

### 日常出图就 4 步

1. **双击桌面 `ComfyUI` 图标**，等浏览器自动打开
2. 点左侧竖排图标里的 **「工作流」**（长得像清单的那个），在「浏览」里点 **`中文提示词出图`**
3. 找到最左边标着 **「① 在这里写中文」** 的框，把你的需求用中文写进去
   （框里已经填好一段示例，直接改成你要的就行）
4. 点界面上的 **执行 / Run** 按钮（或按 `Ctrl + Enter`）
   等约 1 分钟，图就出来了

**出的图在哪**：`D:\AI\ComfyUI_windows_portable\ComfyUI\output\`，
同时界面最右边「出图结果」节点里会直接显示。

### 那条工作流长什么样

从左到右一条流水线，**你只需要动第 1 个框**：

```
① 在这里写中文
      ↓ 自动翻译成英文标签
② 翻译结果（自动）        ← 只是给你看翻了啥，不用管
      ↓
正面提示词（来自翻译）     ← 空的就对了，它由上面喂入
      ↓
   采样器（参数不用改）    ← 28步 / CFG 6 / Euler a，已是二次元推荐值
      ↓
   出图结果
```

右边还有两个不用动的：`CheckpointLoaderSimple`（自动选好了 Illustrious 模型）、
`负面提示词`（通用的，一般不用改）。

### ⚠️ 如果你看到红色边框的节点

红框 = 那个节点缺东西、跑不了。**最常见的原因是加载了别人的工作流，
里面用了你没有的模型**（比如「UNet加载器」「加载CLIP」这些是 Flux 模型专用的，
你的机器上没有 Flux 模型）。

**解决办法：别用那个工作流，改用 `中文提示词出图`。** 它是专门为你这台机器配的。

### 📱 用手机出图（局域网网页版）

**想在手机上出图**，双击 **`启动手机出图.bat`**。

> **推荐：双击桌面 `手机出图一键启动`**
> - 自动检查并启动 **ComfyUI（8188）** 和 **手机网页服务（8800）**，已经在跑的不会重复开
> - 两个服务在最小化窗口里运行，任务栏可以还原看日志；关掉窗口就停止对应服务
> - 网页服务就绪后自动打开 `https://127.0.0.1:8800/`
> - 如果 ComfyUI 还在加载，网页会先打开，等一两分钟再点出图即可

服务**永远只监听电脑自己的热点网卡**（`192.168.137.1`），
校园网、公共 WiFi 里的设备**根本连不上**——这是第一道保护。

**第 1 步：在电脑上开热点**
设置 → 网络和 Internet → **移动热点** → 打开

**第 2 步：手机连上这个热点**

**第 3 步：手机浏览器打开**
```
https://192.168.137.1:8800
```
第一次会提示自签证书「不安全」，点 **高级 → 继续前往** 即可；之后是加密连接。

就能看到一个手机版的出图页面：
写中文 → 选竖图/横图/方图 → 点「出图」→ 约 1 分钟后图直接显示在手机上。

> 如果黑窗口提示「未检测到热点网卡」，就是**热点没开** ——
> 按第 1 步打开后重启服务即可。

#### 🔒 再给热点加一道密码（建议）

热点本身已经有 WiFi 密码，但你还想再锁一层的话：

**第 1 步：双击 `安全设置.bat`**，选 **`1`** 修改管理员密码（至少 8 位）

**第 2 步：重启 `启动手机出图.bat`**

之后无论是电脑还是手机打开这个页面，都会先看到登录框：

- **管理员账号：`admin`**，密码就是你原来设的访问密码
- 普通账号由管理员在 **「3D 星图 → 安全网关 → 用户管理」** 里创建
- 登录一次管 **30 天**，之后不用反复输（清理浏览器数据后会掉）
- 同一 IP 连错 **5 次锁 10 分钟**，防止别人暴力猜
- 想退出：页面「更多 ▾」→ 最下面「退出登录」
- 忘记管理员密码：`安全设置.bat` → 选 `2` 重置为 `admin / admin`，登录后马上改掉

> 升级到多用户后，旧登录会话会失效，需要重新登录一次；
> 账号密码存的是 **PBKDF2-SHA256 哈希**（20 万轮 + 随机盐），不是明文。
> 就算有人翻到 `users.json` 也看不到密码本身。

**多用户和权限（2026-10-19）**

- **管理员**登录后，打开 3D 星图 → 过滤条「安全网关」→ **用户管理** 星球：
  - 创建 / 删除账号、启用 / 禁用、重置密码
  - 给每个普通账号设置限额：每日张数、图库上限、存储上限、上传大小 / 像素、
    最大步数、单次张数、同时任务数、是否允许视频 / 放大 / 挂机、可用底模列表
  - **版本额度**：分享版最多 5 个启用账号（含管理员）、2 台算力节点；
    商用版最多 50 个账号、20 台节点。停用/删除账号、移除节点会释放名额；
    达到上限时创建账号和生成接入码按钮会自动禁用，后端也会再校验一次
- **普通账号**只能看到自己的图库、任务和统计；不能打开用户管理，也访问不到别人的图片。
- **文件按账号分开存**：
  - 图片：`generated\<账号ID>\<模型名>\...`
  - 上传隔离区：`web_uploads\<账号ID>\...`
  - 管理员 ID 是 `admin`，普通账号是 `u_` 开头的 ID
  - 原有图片已自动迁到 `generated\admin\...`
- 删除账号时**保留文件**；管理员可以在图库的「全部用户」筛选里继续看到这些图。
- 管理员图库多一排 **用户筛选**；普通账号没有这一排。
- 禁用账号会立即踢掉它的登录会话，并停止它正在跑的任务。

**平面管理员后台（2026-10-19）**

- 管理员登录后，主页面顶部会多出 **「后 台」** 标签；普通账号看不到。
- 顶部统计卡清楚显示：账号数 / 启用 / 在线、图片总数 / 今日新增、存储、
  今日和本月流量、本月 GPU 秒、任务运行和排队数。
- 账号列表显示每个账号的图片、今日新增、存储、流量、请求、GPU、运行/排队、
  默认主页、限额和关闭的功能数。
- 支持搜索账号；勾选后可批量：
  - 启用 / 禁用 / 删除（删除时保留文件，不能操作当前登录账号）
  - 批量限额：每日张数、图库上限、存储、流量、步数、张数、同时任务；
    留空的字段不修改
  - 批量功能开关：每个功能可选「不变 / 开启 / 关闭」
- 后台每 10 秒自动刷新一次，也可以点「刷新」手动读取。
- 批量接口只对管理员开放，普通账号调用返回 403，并记录安全日志。
- **后台事件不会广播给普通账号**：管理员后台的刷新/状态事件只通过
  `/ws/activity` WebSocket 定向推送给当前管理员本人，普通账号连不上这个通道；
  封禁账号、删除图片、创建/修改/删除账号、批量操作等敏感动作只写日志，
  星图和主页面都不会出现对应的闪烁或状态播报。

**个人设置：默认主页（2026-10-19）**

- 登录后点右上角 **⚙**（或「更多」里的「个人设置」）打开个人设置。
- 「默认主页」有两个选项：
  - **传统平面工作台**：普通网页工作台，适合新手。
  - **沉浸式 3D 星图**：登录后直接进入 `/universe`。手机端不显示这个选项，
    登录也会自动回平面工作台。
- 点「保存」后写入当前账号的 `users.json`（`default_home`），下次登录时由登录接口自动跳转。
- 新账号、未设置过的账号默认是**平面工作台**。
- 星图右上角也有 **⚙**，会打开平面工作台的个人设置弹窗。
- 个人设置里可以**修改密码**：输入当前密码 + 两次新密码（至少 8 位）。
  修改成功后当前登录保持有效，其他设备下次登录要用新密码。
- 个人设置里可以**开启浏览器通知**：开启后页面在后台时，出图完成/失败会弹
  系统通知；浏览器需要用户点一下按钮才会授权。

**本地小参数大模型翻译（2026-10-20）**

- 除了默认的 Argos，本程序可以接入 **Ollama** 或 **OpenAI 兼容** 的本地
  小模型做中文→英文提示词翻译。
- 管理员在「后台 → 系统设置」里填写：
  - 接口类型：Ollama / OpenAI 兼容（LM Studio、llama.cpp server、vLLM 等）
  - 地址：例如 `http://127.0.0.1:11434` 或 `http://192.168.137.20:1234`
  - 模型名：例如 `qwen2.5:1.5b`、`qwen3:1.7b`
  - 可选 API Key；留空表示不修改已保存的密钥。
- 出于安全考虑，只允许 **本机或内网地址**（127.0.0.1、10/8、172.16/12、
  192.168/16、169.254/16 等），不能填公网地址，避免把提示词发到互联网。
- 配置保存后可点 **「保存并测试」**，用一句示例中文检查连接和输出。
- 普通账号在 **个人设置 → 提示词翻译** 里自己选择：
  - **Argos 离线翻译**：默认，轻量稳定；
  - **本地大模型翻译**：只在本机/局域网模型已启用时可选。
- 本地模型失败时会自动回退 Argos；两边都不可用时会明确提示，而不是悄悄
  把中文直接塞给模型。
- 配置存在安装目录的 `local_llm.json`。不要把含 API Key 的文件发给别人；
  备份工具会把它一起备份，备份 ZIP 也要妥善保管。

**24 小时游客账号（2026-10-20）**

- 管理员在「后台 → 账号管理」点 **「生成 24 小时游客」**，会创建一个 `guest_` 开头的
  临时账号，并弹出 **一次性明文密码**（只显示这一次）。
- 游客默认限额：每天 60 张、图库 120 张、存储 500MB、单次最多 2 张、
  同时 1 个任务；**不开视频、放大、挂机**，可以文生图、图生图、局部重绘、
  上传参考图和浏览自己的图库。
- 账号 24 小时后自动过期：服务会踢掉会话、停止正在跑的任务、暂停它拥有的
  算力节点；账号和图片保留，管理员可以手动删除或点「续期 24h」。
- 游客和普通账号一样只能看自己的图片；不能进入后台、用户管理或安全日志。
- 管理员可以像普通账号一样单独调整游客的限额和功能开关。
- 普通账号也在同一块「账号管理」里点 **「创建账号」**，填写用户名、密码和角色。

**多账号并发与排队（2026-10-19）**

- 8GB 显存一次只能跑一个任务，所以所有账号共用一条 **公平队列**：
  先来先排，但按账号轮流放行（A 一个、B 一个、A 一个……），
  不会让一个人的连续任务把别人堵在后面。
- 每个任务提交后先进入「排队中」，轮到它才真正交给 ComfyUI；
  排队时显示 **前方还有几个任务** 和预计等待时间。
- 普通账号的「同时任务」限额限制的是 **排队 + 运行** 的总数，默认 1；
  管理员可在用户管理里调高，单账号最多 20 个位置。
- 全局最多 60 个等待任务；满了会直接提示，不会无限堆积。
- 取消排队中的任务**不会**打断其他账号正在采样的任务；
  只有确定轮到自己的任务在跑时才会中断 ComfyUI。
- 挂机造图也是排一个跑一个，不会一次把队列塞满。
- 主页面状态栏、星图生成舱、星图任务/队列面板都会显示排队位置。
- 主页面右下角新增 **「排队生图」悬浮窗**：显示当前任务进度、排队位置和预计等待；
  点标题可以折叠 / 展开，折叠状态会记住。管理员还能看到任务属于哪个账号。
- 任务完成时会弹出 **完工窗口**：显示结果图 / 视频、提示词、模型、耗时和种子，
  可以直接「查看结果」「再来一张」或关闭。另一个界面发起的任务完成后，这里也会弹。
- 星图里原有的 **NEW SIGNAL** 小卡片继续作为星图侧的完成提示。

**局域网算力共享（2026-10-19）**

- 现在除了本机，还可以把局域网上其他装了 ComfyUI 的机器接进来。
  每台机器运行自己的 ComfyUI，中央把整张图片任务派给空闲节点；
  这是**任务级并发**，不是把一张图拆到多张显卡上算。
- 管理端：主页面「后台 → 算力节点」。
  - **生成接入码**：8 位、一次性、15 分钟有效。
  - 在 worker 机器上运行 `worker/盘点本机算力.bat` 盘点，再运行
    `接入算力节点.bat`（或按弹窗里的命令）接入。
  - 管理员审批时设置 **所有者**、**可信节点** 和 **账号白名单**。
    普通账号只能使用“可信 + 白名单内”的节点；管理员不受限。
  - 节点卡片显示在线、GPU / 显存、模型数量、缺模型列表、当前任务和统计。
  - **暂停/恢复**：管理员可暂停任意节点；节点所有者也可以在「个人设置 →
    我的算力节点」里暂停自己的机器。暂停后只停新任务，当前任务默认跑完。
  - **本机接单**开关：关闭后本机不再接新任务，只跑远程节点；适合测试或
    本机专心做别的事。
  - **启用远程算力**总开关：默认关闭，确认节点审批/权限后再打开。
- worker 端：
  - 只主动连中央 HTTPS 8800，不需要在 worker 上开局域网端口；本机控制页只绑
    `127.0.0.1:8199`。
  - 支持 `暂停接单.bat` / `恢复接单.bat`；控制页能看到当前任务和上次错误。
  - 任务结束会尽量清理 worker 上的临时输入/输出；模型和自定义节点需要
    手工复制，后台会显示每台节点缺哪些模型。
  - 详细步骤见 `worker/README_算力节点.md`。
- 调度规则：
  - 默认 **本机优先，远程溢出**：本机空闲先用本机，本机忙时才派远程。
  - 仍然保留按账号“最久未服务优先”的公平性；每个节点同时只跑一个任务。
  - 主页面 / 星图的进度、排队浮窗、完成弹窗会显示实际执行节点名称。
  - 远端节点失联、重启或执行中断，且还没有回传过图片时，会自动排除失败节点，
    换本机或其他节点重试 **一次**；已经回传过图片的任务不重试，避免重复出图。
    没有备用执行器时直接报错并释放队列。
  - 普通账号默认同时任务 1 个；要真正利用多台机器，可把账号的
    「同时任务」调大，或让多个账号同时提交。
- 网络与隐私：
  - 只接受本机 + 热点 `192.168.137.0/24` 的 worker；校园网 `172.24.x`
    和任何其他网段都会被拒绝；服务仍然只绑 `127.0.0.1` + `192.168.137.1`。
  - worker 执行时本机能从 ComfyUI 工作流看到提示词；所以只把“可信”开关
    打开给你信任的机器，白名单只加允许使用的人。
  - 接入码、`worker_agent.json` 里的 secret、`cert.pem` 都不要外传。
- 当前限制：第一阶段只支持文生图 / 图生图 / 局部重绘；放大、视频仍在本机。
  中央服务必须在线；中央重启会丢内存中的队列/运行任务（和以前一样）。
  模型按文件名匹配，同名不同权重需要自己保证一致。

**一键还原点 / 回滚 / 系统重置（2026-10-20）**

- 入口：管理员「后台 → 系统设置 → 系统维护」。
- **创建还原点**：把 `users.json`、`workers.json`、`usage.json`、
  `jobs_state.json`、`local_llm.json`、`monitor.json`、`cleanup.json`、
  `queue_control.json`、`teams.json`、`team_prompts.json`
  打包到 `_restore_points/`，最多保留最近 20 个。
- **回滚到这个点**：先自动再备份当前状态，然后恢复账号、节点、用量、任务状态
  和翻译设置；**不会删除或回滚图片、模型、证书、日志**。正在跑的任务会停止。
- 回滚后如果当前管理员在还原点里不存在，会自动退出登录。
- **系统重置**：保留当前管理员和所有图片，清空其他账号、任务、用量和算力节点，
  并关闭本地翻译；重置前同样会自动创建还原点，所以可以马上回滚。
- 还原点 ZIP 含账号密码哈希和 worker secret 哈希，请按备份文件同等级别保管。
- 还原点只用于配置级回滚；需要连图片一起恢复时，仍使用 `备份数据.bat`
  的完整备份 / `恢复数据.bat`。

**监控中心与告警（2026-10-20）**

- 入口：
  - 平面端管理员「后台 → 系统设置 → 监控告警」：调阈值、Webhook、metrics token；
  - 星图「监控中心」分类：健康总览、告警中心、一键诊断、任务时间线、趋势、
    容量预测和节点遥测，都是实时面板。
- **健康总览**：综合 GPU / 显存、队列、错误率、节点在线、磁盘和证书，
  给出 0–100 分以及「良好 / 需关注 / 降级 / 严重」。
- **告警中心**：监控以下情况并保留历史：
  - 外部程序占用 GPU 过高、GPU 温度过高；
  - 队列积压、ComfyUI 离线；
  - worker 掉线（30 秒）和严重掉线（120 秒）；
  - 任务卡住（默认 20 分钟无进展）；
  - 最近 10 分钟错误率过高、磁盘剩余不足、HTTPS 证书快到期。
  活动告警可以「确认」，恢复后会自动从活动列表移除；历史仍可查。
- **一键诊断**：检查 ComfyUI、底模目录、Anima / Wan 三件套、自定义节点、
  算力节点、队列与卡住任务、磁盘、证书、临时上传、翻译配置和版本锁定，
  每项给出「通过 / 提示 / 警告 / 错误」和处理建议。
- **任务时间线**：从错误列表或任务列表点「查看时间线」，能看到排队、派发、
  首帧采样、保存图库各阶段的耗时；普通账号只能看自己的任务。
- **趋势与容量**：24 小时 / 7 天任务量、成功率和 GPU 秒；按最近 7 天图库增长
  估算剩余可用天数，空间充足时显示「>10 年」，不会出现荒唐大数。
- **节点遥测**：worker 心跳用 `nvidia-smi` 上报 GPU 利用率、显存和温度，
  面板显示最近 5 分钟走势；节点详情和算力节点卡片都能看。
- **异常聚焦**：星图过滤条的「异常聚焦」只显示监控节点、当前告警相关节点和
  正在运行的任务链，方便一眼看到问题在哪。
- **Webhook**：可填企业微信 / 飞书 / Slack 等接收地址；告警触发时 POST JSON，
  默认 5 分钟冷却，后台可「测试发送」。地址可能含密钥，只保存在本机
  `monitor.json`，不会回显给普通账号。
- **Prometheus**：后台生成 token 后，抓取
  `https://127.0.0.1:8800/metrics?token=...`（也支持 Bearer）。
  指标包括 `mgs_up`、队列、运行任务、节点在线、GPU、显存、错误数、图库和
  告警数量。未启用或 token 不对时返回 404。
- 阈值保存在 `monitor.json`，告警历史 `monitor_alerts.json`，趋势
  `monitor_trends.json`；备份工具会包含这些文件，但不要公开分享。
- 权限：健康、告警、诊断、趋势、容量和监控设置仅管理员；普通账号只能看
  自己的任务列表和时间线，以及自己的在线状态。

**自动磁盘清理（2026-10-20，默认关闭）**

- 入口：管理员「后台 → 系统设置 → 自动磁盘清理」。

  - **低于剩余 GB 时触发**：磁盘剩余高于这个值就完全不动；

#### ✨ 几个好用的功能

**采样器**（「更多 ▾」→ 采样质量下面）

默认 `Euler a`，这是 Illustrious 官方推荐值。想换画风可以试 `DPM++ 2M`，

**画质增强 PAG**（「更多 ▾」→ 画质增强 PAG）

默认开启。它在每步采样时多做一次**扰动注意力**计算，同一个种子下线条、蕾丝、

**国漫风格**（提示词上方的风格条）

- **国漫淡彩**：色彩清淡、低饱和、柔和光线、干净线条，接近现在国漫插画的感觉。
- **国漫水墨**：淡彩基础上加水墨留白，适合古风、山水、汉服题材。

风格词会和你的提示词一起送进翻译节点。想保住汉服、竹林这类元素，
把它们明确写进提示词里；风格词只负责调色和线条。

  3 秒约 **4 分钟**；4 秒以上在 8GB 上很可能失败
- 首次生成会慢一些（要加载 6.7GB 的文本编码器）
- 结果直接在图库和查看器里播放，也能保存到手机

**说清楚它的局限**：

- 短视频，不是长视频；4 秒以上只建议试一次，界面会标成橙色警告
- 8GB 显存跑 4 秒以上很容易爆（以前实测 4 秒 65 帧在解码阶段被中断），
  所以默认推荐 1~2 秒
- 画风偏「动画电影」，和你用 Illustrious 出的静态图不完全一致

文件存在 `generated\<模型目录>\`，格式 **mp4（H.264）**，手机浏览器能直接播。
`ComfyUI\output\video\` 里保留原件。

#### 📽 图生视频（Wan 2.1 VACE 1.3B）

### 🖼 图生图 / 局部重绘

手机页面上除了「文生图」，还有另外两个模式：

| 模式 | 作用 |
|---|---|
| **文生图** | 纯靠文字生成 |
| **图生图** | 传一张参考图，照着它的构图/风格改 |
| **局部重绘** | 在图上涂一块，只重画涂到的地方 |

#### 参考图不要传太大的（已自动处理）

8GB 显存能直接跑的参考图上限约 **1.3 MP**（比 1152×1152 略小）。
超过就会卡死 —— 浏览器一直转圈，ComfyUI 也跟着僵住，只能强制关掉重来。

**现在已经加了自动降分辨率**：参考图超过 1.3 MP 时，会在编码前先等比缩小，
比例保持不变、不会拉变形。实测：

| 你传的参考图 | 尺寸 | 结果 |
|---|---|---|
| 手机截图 | 832×1216（1.01 MP） | 原样处理，不缩放 |
| **实测 12 MP 大图** | 4624×2600 | ✅ 自动缩到 1560×872，58 秒出图 |

> **副作用要提前知道**：图生图的**画幅由参考图决定**，所以参考图被缩小了，
> 出图尺寸也跟着变小。想要大尺寸成品的话，**先用图生图出小图，再点放大**。

> 判断标准很简单：**出图尺寸 ≈ 参考图尺寸**（缩放后）。
> 你传 832×1216 就出 832×1216；传 12 MP 的大图，就出 1.3 MP 左右的图。

## 零点五、多人使用、队列与团队

### 排队规则

- 多账号不是按“谁先点谁先跑”，而是按 **预计 GPU 成本加权公平**：
  图片、放大、视频会分别估算耗时，累计消耗少的账号优先。
- 交互任务优先于挂机任务；挂机任务等久了会自动提升优先级，不会被饿死。
- 页面会显示：排队位置、预计开始时间范围、预计完成时间范围。
- 每个账号的“同时任务”限制同时包含排队 + 运行，默认 1 个。
- 管理员后台 →「任务队列」可以：
  - 全局暂停接单（正在跑的任务继续）；
  - 暂停某个账号的队列；
  - 给账号加优先级（0~100）；
  - 取消某个账号所有排队任务；
  - 设置最长等待时间（0 = 不限，超时自动失败并提示）；
  - 设置维护窗口（例如每天 02:00–04:00 暂停新任务）。
- 服务还提供 `queue_control.json` 持久化这些设置；系统重置会恢复默认。

### GPU 时间配额

管理员在后台账号限额里新增了：

- 每日 GPU 秒（0 = 不限）
- 每月 GPU 秒（0 = 不限）

提交任务时会按预计耗时预检查；实际 GPU 秒在任务完成后记入 `usage.json`。

### 团队 / 项目

图库页顶部有「个人图库 / 团队名 / 团队管理」：

- 团队所有者可以创建团队、按用户名添加成员、设置编辑者 / 只读；
- 团队图库是 **成员个人图库的聚合视图**，不复制图片，不改变每人的存储配额；
- 共享提示词库：编辑者和所有者可添加，创建者或所有者可删除；
- 删除图片仍然只能删自己的，团队角色不会扩大写权限；
- 默认仍是账号隔离，只有显式加入团队才共享视图。

### 登录设备

个人设置 →「登录设备」可以查看最近登录的 IP、浏览器和最后活跃时间；
可以退出指定设备，或一键退出除当前设备外的所有登录。
管理员也可以通过 `/api/sessions` 指定账号强制下线。

### 用量导出

管理员后台右上角「导出用量 CSV」会把每个账号每天的请求数、上下行流量、
图片数、GPU 秒、任务数导出为 CSV；也支持 `format=json`。

### 任务状态 Webhook

后台 → 系统设置 → 监控设置里，除了告警 Webhook，还可以打开「任务状态通知」：
任务开始 / 完成 / 失败时向 Webhook 发一条 JSON，只含任务号、模型、耗时、
状态和错误摘要，**不含提示词和图片**。可对接 QQ / 微信 / 飞书机器人网关。

### 企业反向代理认证（可选）

如果企业用 nginx / Caddy / OIDC 网关做统一登录，可以让网关把用户名放到请求头，
再启动服务时设置环境变量：

```bat
set MGS_TRUSTED_PROXY=1
set MGS_PROXY_HEADER=X-Remote-User
python_embeded\python.exe -s mobile_web.py
```

只有来自 `127.0.0.1` / `::1` 的请求才会信任这个头，局域网其他机器无法伪造。
不设置这两个变量时，行为与普通账号密码登录完全一致。

**Anima（2026 年）** 是比 Illustrious 新一代的动漫模型，参数只有 2B，8GB 显存跑起来更宽裕，
提示词遵循度也更好（写汉服不会给你白 T 恤）。网页顶部的模型条可以在
Anima / NoobAI / Juggernaut / Illustrious / RealVis 之间切换，Anima 官方推荐参数是
**30 步 / CFG 4**，切到 Anima 时会自动设好。

> Anima 用不了 SDXL 的 LoRA，PAG 也还没适配；网页里选中它时，这两块会自动变灰。
> 需要 LoRA 的风格请切回 Illustrious。

**Anima 极速模式**（「更多 ▾」→ Anima 极速）：套官方 Turbo LoRA，固定 **8 步 / CFG 1**。
实测热跑一张 **14 秒**（正常 30 步约 57~67 秒），画面细节略少，但构图和配色基本一致，
适合抽卡、快速试提示词。选中 Anima 时这一块才会出现。

**NoobAI-XL Vpred**（模型条第二项）：Danbooru/e621 标签覆盖最全，冷门角色、画师、
作品名最准，适合「画某个具体角色」。官方 Vpred 线最新就是 **1.0**；1.1 官方只有
epsilon 版，网上所谓「Vpred 1.1」是社区转的，没有采用。

- v-pred 模型需要特殊采样：网页会自动加 **clip skip 2 + v_prediction + RescaleCFG**，
  采样器**固定 Euler**，30 步 / CFG 4.5，不用你手动设。
- 实测热跑 30 步约 **52~56 秒**（首次含加载 74 秒）。
- **中文提示词会丢角色名**：Argos 会把「初音未来」译成「the first-sounding future」。
  想画指定角色，整段提示词请用英文标签（例如 `hatsune miku, 1girl, twintails, ...`）；
  普通中文描述可以直接写，网页会自动补一段英文质量/动漫标签，避免画成 2.5D。

**风景照片用「写实 · Juggernaut XI 风景」**：Juggernaut XI v11 是 v9 的全面升级，
手、脸、构图和提示词遵循都更好，山、湖、森林、日出日落、城市街景都擅长。
选中它会自动切到**横图 1216×832**、DPM++ 2M、30 步 / CFG 5。
提示词写清楚**地点 + 时间 + 光线 + 镜头**，比如「黄昏的雪山和湖泊，湖面倒影，
长曝光云层，超广角镜头，金色阳光」，比只写「美丽的风景」效果好得多。
实测热跑 30 步约 81 秒（首次要加载 6.6GB 模型，会再慢 15 秒左右）。
放大写实/风景图时会自动优先用 `4x-UltraSharp`，比原来的通用 RealESRGAN 更锐。

**Illustrious XL 属于 SDXL 生态**，比 SD1.5 系（Anything V5、MeinaMix 那些）画质和手部结构好很多，
缺点是慢一些、吃显存。以后你找 LoRA 要认准 **"Illustrious" 或 "SDXL"** 标签的，
SD1.5 的 LoRA 和它不通用。

### 自动适配与新手引导

网页不只看模型文件名：它会读取 `.safetensors` 头部的元数据和张量名，判断这是
Anima、SDXL 动漫、SDXL 写实、Pony、NoobAI v-pred、SD1.5、Flux 还是 Qwen-Image，
然后自动给出推荐画幅、步数、CFG、采样器和风险提醒。

**画幅会跟着底模变**：选中模型后，「画面比例」里列的是这个模型擅长的尺寸
（例如 Anima/SDXL 有 832×1216、1216×832、1024×1024、768×1344、1536×864；
SD1.5 只列 512×768、640×640 这类小图）。每个模型还有单边和总像素上限，
手填的宽高会先对齐到 16 的倍数，超限时自动等比缩小，避免直接把 8GB 显存跑爆。
实测 Anima 极速 1536×864 仍能正常出图，SD1.5 手填 1024 会落到 768×768。
星图的生成舱也使用同一套模型画幅和视频时长选项。

- 模型 chip 上的 **★** 表示新手推荐；`v-pred`、`SD1.5`、`加速模型` 等徽标表示特殊用法。
- 选中模型后，模型条下方会出现建议卡，例如“SD1.5 原生 512，直接开 1024
  容易出双头”，并给出 **按推荐设置** 按钮，一键套用画幅、步数、CFG、采样器。
- 选 Anima 时自动灰掉 SDXL LoRA 和 PAG；选不支持负面的模型时负面输入框也会灰掉。
- 认出 Turbo/Lightning/LCM 加速模型时，会自动降到 5~8 步、CFG 1~2，避免糊图。
- Flux / Qwen-Image 目前只做识别；如果模型没有内置文本编码器和 VAE，网页会直接
  提示暂不适配，避免跑到一半报错。
- 没识别出的模型会按通用 SDXL 参数保守推荐，并提醒你可以在文件名里带
  `sd15` / `sdxl` / `pony` / `flux` 方便下次识别。

**新手怎么选**：动漫先用 Anima 2B 或 Illustrious；写实先用 RealVis；想用 Pony
标签体系再选 Pony；老显卡或快速草图用 SD1.5。先点 **按推荐设置** 出第一张，
不要一上来就把画幅拉到 1536 或把步数拉到 60。

模型下载器新增两个可选包：`pony`（Pony Diffusion V6 XL）和
`animagine`（Animagine XL 4.0），都可以在安装时或之后双击 `模型下载.bat` 补装。

Pony 系会自动补 `score_9, score_8_up, score_7_up`，你自己写了就不会重复加。
LoRA 现在会按底模家族过滤：SDXL 模型只显示 SDXL LoRA，SD1.5 模型只显示 SD1.5
LoRA，避免选到不兼容的文件后出废图。

### 任务状态与重启

排队、运行和最近完成的任务会写入 `jobs_state.json`（只含状态、模型、耗时、
图片相对路径，不含提示词或输入图路径）。服务重启后：
- 最近完成的任务仍能通过 `/api/status/<id>` 查到；
- 被重启打断的排队/运行任务会明确显示“服务重启，任务已中断”，不会变成 404；
- 中断的任务不会自动重跑，避免重复出图。

### 断电 / 断网 / 文件损坏

- **ComfyUI 突然关闭或重启**：运行中的任务约 22 秒内标为失败
  “ComfyUI 连接中断”，并释放调度槽位；不会卡住 15 分钟。ComfyUI 恢复后可直接重新提交。
- **网页服务被强杀**：重启后从 `jobs_state.json` 恢复最近任务；被打断的排队/运行任务
  标为“服务重启，任务已中断”，不会重复出图。
- **账号文件损坏**：每次保存账号会保留一份 `users.json.bak`；主文件损坏时自动从
  备份加载，避免账号全部丢失或退回默认管理员。备份文件含密码哈希，不要公开分享。
- **日志/队列/监控等状态文件损坏**：会回退默认值继续启动；坏文件不会阻止服务运行。
- **上传中途断电**：只会留下 `_node_uploads` 临时分块，不会安装半个节点；
  可在后台重新上传，24 小时后临时文件也会自动清理。
- 完整的故障演练记录见 `docs/极端测试报告_20261020.md`。

## 五、怎么写提示词（Illustrious XL）

> ### ⚠️ 提示词必须写英文，中文完全无效
>
> 实测：同一模型、同一随机种子、同一参数，只把提示词换成中文，
> 结果是**一张纯噪声的抽象色块图，连人形都没有**——比留空还糟。
>
> 原因：文本编码器（CLIP）只用英文 danbooru 标签训练过，中文在它眼里是乱码。
>
> **中文对照表看 `提示词标签速查表.md`**，里面有 11 大类常用标签的中英对照、
> 现成模板、以及"只记 30 个词"的偷懒方案。

Illustrious 系是用 **danbooru 标签**训练的，所以要用**英文的标签词**，用逗号分隔，不要写自然语言长句。

### 正面提示词模板

```
masterpiece, best quality, very aesthetic, absurdres,
1girl, solo, long hair, black hair, blue eyes, school uniform,
standing, looking at viewer, classroom, sunlight,
detailed background, depth of field
```

- 前 4 个是**质量标签**，Illustrious 靠它们"提神"，建议固定带上
- `1girl, solo` 控制人数
- 中间描述人物特征：发色、瞳色、服装
- 后面描述动作、场景、光线

### 负面提示词模板（通用，直接抄）

```
lowres, worst quality, low quality, low score, bad score, average score,
bad anatomy, bad hands, bad proportions, missing fingers, extra digits,
fewer digits, extra limbs, fused fingers, text, error, signature, watermark,
username, blurry, jpeg artifacts, cropped
```

### 推荐参数

| 参数 | 建议值 | 说明 |
|---|---|---|
| 分辨率 | **832 × 1216**（竖构图）| 人物立绘用这个；横构图反过来；方图 1024×1024 |
| 采样器 | `Euler a` | Illustrious 官方推荐 |
| 步数 Steps | 28 | 25~32 之间都行，再高收益很小 |
| CFG | 6 | 5~7 之间；太高会画面发苦、过饱和 |
| 随机种子 Seed | 固定住可以微调 | `control_after_generate` 设为 `fixed` |

> **分辨率千万别乱填**，比如 512×512 或 1920×1080 这种非训练分辨率，
> 出来会人体崩坏、出现双头。要么用上面推荐值，要么先小图再用高清放大。

### 中文提示词自动翻译（已装好）

装了 **AlekPet** 节点包，能让 ComfyUI 自动把中文翻成英文。
节点位置：右键画布 → `Add Node` → `AlekPet Node`

**离线方案（推荐，不联网）**

| 节点 | 说明 |
|---|---|
| `Argos Translate Text Node` | 中文进 → 英文字符串出 |
| `Argos Translate CLIP Text Encode Node` | 中文进 → 直接输出 conditioning（省一个节点） |

连线方式：`Argos Translate Text Node` 的 text 输出 → 接到 `CLIP Text Encode` 的 text 输入。
`from_translate` 选 `chinese`，`to_translate` 固定是 `english`。

**在线方案**：`Deep Translator Text Node` —— 实测只有 **MyMemory** 引擎能用
（Google、googletrans 在你的网络下都不通）。质量与离线版接近，还需联网，所以**不推荐**。

> ### ⚠️ 机器翻译 ≠ danbooru 标签
>
> 纯翻译引擎输出的是**自然英语**，不是模型训练用的标签。
>
> | 你的中文 | 机器翻译输出 | 真正的 danbooru 标签 |
> |---|---|---|
> | 双马尾 | `Two ponytails` | `twintails` |
> | 夜景 | `night visions`（错译） | `night` |
> | 电影感光线 | `movie light` | `cinematic lighting` |
> | 一个女孩 | `A girl` | `1girl` |
>
> **当前用的是 Argos 机翻**（输出自然英语），这是实测下来出图效果最合口味的做法。
>
> 曾经试过「词表优先」的标签转换（内置 400 条中文→danbooru 词表 + 自动补质量词），
> 结果画面偏油腻、风格被拉向模型的默认审美，**已回退**。
> 代码还留在 `prompt_engine.py` 里（开关 `USE_PROMPT_OPTIMIZER` 在 `app_core.py`），
> 想再试改那个开关即可。
>
> **想确认模型到底收到了什么**：点网页上的 **「看译文」**。
>
> 追求最精确的控制，还是用 `提示词标签速查表.md` 自己拼英文标签。

> **离线翻译为什么需要特殊配置**：Argos 默认用 stanza 做中文分词，而 stanza 要从
> `raw.githubusercontent.com` 和 `huggingface.co` 下模型——这两个域名在你的网络下都不通。
> 所以启动脚本里加了 `set ARGOS_CHUNK_TYPE=MINISBD` 强制改用本地 MiniSBD 分词器，
> 中文语言包也已经下好装在本机，**现在翻译全程离线**。

## 六、显存不够怎么办（8GB 的关键点）

你这张卡标称 8GB，但**桌面程序本身已经占掉 1~2GB**
（你没关的浏览器、WeChat、QQ、Wallpaper Engine 都在吃显存），
所以 ComfyUI 实际能用的大概 7GB 左右。

**实测显存占用**（一次 832×1216 出图）：

```
SDXLClipModel（文本编码器）   1560 MB
SDXL（主模型 UNet）           4896 MB
AutoencoderKL（VAE）           159 MB
                       合计 ≈  6615 MB
```

总共约 **6.6GB**，可用约 7.3GB —— **刚好装得下，但余量只有几百 MB**。
这就是为什么下面第 1 条（关掉占显存的程序）最有效：一旦其它程序多占了 700MB，就会爆。

按优先级处理：

1. **出图前先关掉浏览器标签页 / 游戏 / 视频播放器**，最有效，能多腾出 1~2GB
2. **分辨率不要超过 1216×1216**，一次别生成超过 2 张
3. 还是不行 → 换用 `启动ComfyUI_低显存模式.bat`
4. 想放大出大图，**别直接提高分辨率**，用 `UltimateSDUpscale` 节点分块放大

**关于 `--lowvram` 参数（重要）**：网上大量教程让你加 `--lowvram`，但在这套新版 ComfyUI 里
**它已经失效了**。v0.40.0 帮助文档原文是 `Doesn't do anything if dynamic vram is enabled`
（动态显存开启时该参数无任何作用）。新版用的是自动"动态显存 + 异步权重卸载"，
已经自动把模型在显存和内存之间调度了。所以不用手动加这个参数。

## 七、常见问题

**Q：浏览器打不开 / 显示无法连接**
A：等 30~60 秒。首次启动要加载组件，比较慢。黑色窗口里出现
`To see the GUI go to: http://127.0.0.1:8188` 就说明好了，手动复制这个地址到浏览器。

**Q：报 `CUDA out of memory` / 出图是纯黑 / 卡死**
A：见第六节。优先关掉其它占显存的程序。

**Q：管理器的插件列表是空白的**
A：镜像挂了。打开
`D:\AI\ComfyUI_windows_portable\ComfyUI\user\__manager\config.ini`，
检查这两行都在、且值正确：

```
channel_url = https://gh-proxy.com/https://raw.githubusercontent.com/ltdrdata/ComfyUI-Manager/main
default_cache_as_channel_url = True
```

**第二行很关键** —— 它默认是 `False`，此时管理器会绕过你设的镜像、
直接去连被墙的 `raw.githubusercontent.com`，然后刷出一堆 DNS 报错。
换成别的镜像的话，两行要一起换：

```
channel_url = https://ghfast.top/https://raw.githubusercontent.com/ltdrdata/ComfyUI-Manager/main
channel_url = https://ghproxy.net/https://raw.githubusercontent.com/ltdrdata/ComfyUI-Manager/main
```
改完重启 ComfyUI。

**Q：想再下别的模型，但 Civitai 打不开**
A：实测 **civitai.com 和 huggingface.co 在你这条网络下都无法直连**（超时），
官方域名被墙。两个可用路径：
- **HuggingFace 镜像**：把网址里的 `huggingface.co` 换成 `hf-mirror.com`，其余不变。
  例如 `https://hf-mirror.com/OnomaAIResearch/Illustrious-XL-v2.0`
- **GitHub 加速**：在 GitHub 链接前面拼上 `https://gh-proxy.com/`，例如
  `https://gh-proxy.com/https://github.com/用户名/仓库/releases/download/...`

模型文件下载后放进 `ComfyUI\models\checkpoints\`，然后在界面里按 `R`（或点刷新按钮）刷新即可看到。

**Q：装插件时 pip 很慢**
A：已经给便携 Python 配好清华镜像了
（`python_embeded\pip.ini`），正常应该是几 MB/s。

**Q：出图速度大概多少**
A：**已实测**：832×1216 / 28 步 / Euler a，实测 **53.6 秒**（这是含模型加载的首次出图）。
第二张起模型已在显存里，会更快。这个数字可以作为你的基准。
