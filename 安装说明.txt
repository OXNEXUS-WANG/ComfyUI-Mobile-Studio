CometInk 彗墨 · 手机出图
================

一、准备工作
------------
1. Windows 10 / 11 64 位电脑，建议 NVIDIA 8GB 显存以上。
2. 至少 20GB 空闲磁盘（默认模型约 6GB，安装过程还要临时空间）。
3. 能上网；安装器会从 gh-proxy / hf-mirror 下载 ComfyUI 和模型。
4. 手机和电脑要连同一个 Windows 移动热点。

二、安装
--------
1. 把 Setup ZIP 解压到一个普通文件夹（不要在压缩包里直接运行）。
2. 双击“安装.bat”。
3. 选择安装目录，默认：
   D:\CometInk
4. **首次安装会弹出醒目的免责声明与使用协议窗口**：请完整阅读，勾选
   “我已阅读并理解上述免责声明”，再点“同意并继续”。不勾选无法继续；
   点“退出安装”不会修改系统。完整文本也保存在安装包的 DISCLAIMER.md。
   无人值守安装必须显式加 `-AcceptDisclaimer`，否则安装器会拒绝执行。
5. 设置管理员密码（至少 8 位，请记好）。
6. 选择模型包：
   - 直接回车：Anima 2B + 放大模型（推荐，约 6GB）
   - 输入 all：下载全部模型（约 66GB）
   - 输入 n：先不下载，之后双击“模型下载.bat”补装
   可选包新增 Pony Diffusion V6 XL、Animagine XL 4.0；
   安装后网页会自动识别模型家族，并给新手推荐画幅、步数和注意事项。
7. 等待安装完成。中途不要关闭窗口。
   接受记录写入安装目录的 disclaimer_accepted.json，只用于本机判断，
   不包含密码，也不会进入发布包。

三、启动
--------
1. 双击桌面的“CometInk Studio”快捷方式。
2. 电脑浏览器打开：
   https://127.0.0.1:8800
3. 账号：admin
   密码：安装时设置的密码

四、手机访问
------------
1. Windows 设置 → 网络和 Internet → 移动热点 → 打开。
2. 手机连这个热点。
3. 手机浏览器打开：
   https://192.168.137.1:8800
4. 首次提示证书“不安全”时，点“高级”→“继续前往”。

如果手机打不开：
- 确认手机连的是电脑热点，不是校园网/家里 Wi-Fi。
- 确认地址是 https，并且带 :8800。
- 右键“修复手机访问.bat”，以管理员身份运行。

五、补装模型
------------
双击“模型下载.bat”，可以重复运行，支持断点续传。
模型不会提交到 GitHub，也不在安装包内。

想在网页里训练 LoRA（可选）：
1. 管理员登录 → 顶部“训练”标签 → 点“安装训练组件”。
2. 首次安装约 200MB，下载 kohya sd-scripts 和最小依赖到 trainer\；
   不修改 ComfyUI 的 Python 环境，发布包里也不带这些依赖。
3. 安装完成后，在训练设置里打开“启用训练”。
4. 普通账号默认没有训练权限，需要管理员在“用户管理”里单独开启。
5. 推荐 Anima 2B（8GB 显存可跑）；SDXL 为实验性，8GB/16GB 会在加载模型时
   内存不足，建议 12GB+ 显存、24GB+ 内存。
6. 训练期间本机出图会自动暂停，训练结束后恢复；远程 worker 不受影响。

详细步骤见 docs\训练说明.md。

六、多机器算力共享
------------------
把安装目录里的 worker 文件夹复制到第二台机器，
按 worker/README_算力节点.md 接入中央。

九、版本锁定
------------
安装器默认使用 installer\versions.lock.json：
ComfyUI v0.42.0、Python 依赖、自定义节点 commit、模型 revision、7zr 哈希
都已锁定；已有 ComfyUI 默认不自动更新。
升级请使用新安装包，并在测试机验证后再发布。
不要随手加 -AllowUpdates，它会脱离版本锁定。
详见 VERSION_LOCK.md。

十、安装时遇到环境冲突
----------------------
安装器会先体检再动手，能自动适配的会直接处理：

- 系统里设置过 PYTHONHOME / PYTHONPATH / PYTHONUSERBASE：安装器会临时清理，
  避免把便携版 Python 带偏。
- 目录已存在但不是本程序的完整安装：弹窗建议换一个 -Mobile-Studio 子目录。
- 已有 ComfyUI 但没有 python_embeded：提示换目录，避免覆盖原有环境。
- 磁盘空间不足 20GB：询问是否继续安装但不下载模型。
- CometInk / ComfyUI 正在运行：询问是否自动停止；不停止就退出，避免文件被占用。
- 端口 8188 / 8800 被其他软件占用：弹窗显示程序名、PID 和路径，可以继续安装
  （启动前需要先关闭那个程序），也可以取消。
- 已有同名自定义节点 / 模型：先备份到 _node_trash 或 *.bak-时间戳，再继续，
  不会直接删除用户文件。
- 旧 HTTPS 证书过期或缺少本机/热点地址：自动备份并重新生成。

无法自动适配时，会弹出“安装遇到问题”窗口，里面有：
1. 失败阶段和原因；
2. 按情况给出的排查步骤；
3. 诊断报告 install_problem.txt（含端口占用、自动适配记录）；
4. 安装日志 %TEMP%\CometInk-install.log。
点“是”可以直接打开日志和诊断报告。

如果窗口没弹出来（无人值守 / -Yes），同样会生成上述两个文件。
命令行排查时也可以加 -DryRun 只体检、不修改任何文件。

十二、只卖安装程序的商业清洁模式
--------------------------------
双击“安装_商业版.bat”：
- 不下载画图模型，不装 GPL 自定义节点；
- 中文翻译使用 MIT 兼容层 + Argos CC-BY 4.0 模型，不安装 AGPL 的 MiniSBD；
- 已有 ComfyUI 直接复用，不自动更新；
- 没有 ComfyUI 会询问是否下载；
- 加 -NoTranslate 可完全跳过翻译，只使用英文提示词。
高级参数：-SkipComfyUI / -ComfyUIDir <已有 ComfyUI 目录>。
这样安装包里只有自己的安装器和网页代码，ComfyUI/模型/第三方节点由用户选择。
