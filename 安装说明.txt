ComfyUI Mobile Studio · 手机出图
================================

一、准备工作
------------
1. Windows 10 / 11 64 位电脑，建议 NVIDIA 8GB 显存以上。
2. 至少 20GB 空闲磁盘（默认模型约 6GB，安装过程还要临时空间）。
3. 能上网；安装器会从 gh-proxy / hf-mirror 下载 ComfyUI 和模型。
4. 手机和电脑要连同一个 Windows 移动热点。

二、安装
--------
1. 把 Setup ZIP 解压到一个普通文件夹（不要在压缩包里直接运行）。
2. 双击“安装.bat”。
3. 选择安装目录，默认：
   D:\AI\ComfyUI_windows_portable
4. 设置管理员密码（至少 8 位，请记好）。
5. 选择模型包：
   - 直接回车：Anima 2B + 放大模型（推荐，约 6GB）
   - 输入 all：下载全部模型（约 66GB）
   - 输入 n：先不下载，之后双击“模型下载.bat”补装
   可选包新增 Pony Diffusion V6 XL、Animagine XL 4.0；
   安装后网页会自动识别模型家族，并给新手推荐画幅、步数和注意事项。
6. 等待安装完成。中途不要关闭窗口。

三、启动
--------
1. 双击桌面的“手机出图”快捷方式。
2. 电脑浏览器打开：
   https://127.0.0.1:8800
3. 账号：admin
   密码：安装时设置的密码

四、手机访问
------------
1. Windows 设置 → 网络和 Internet → 移动热点 → 打开。
2. 手机连这个热点。
3. 手机浏览器打开：
   https://192.168.137.1:8800
4. 首次提示证书“不安全”时，点“高级”→“继续前往”。

如果手机打不开：
- 确认手机连的是电脑热点，不是校园网/家里 Wi-Fi。
- 确认地址是 https，并且带 :8800。
- 右键“修复手机访问.bat”，以管理员身份运行。

五、补装模型
------------
双击“模型下载.bat”，可以重复运行，支持断点续传。
模型不会提交到 GitHub，也不在安装包内。

六、多机器算力共享
------------------
把安装目录里的 worker 文件夹复制到第二台机器，
按 worker/README_算力节点.md 接入中央。

七、备份与测试
--------------
备份数据.bat    一键备份账号/节点/图库元数据
恢复数据.bat    从备份 ZIP 恢复（先关闭服务）
运行测试.bat    跑单元测试；设置 MGS_TEST_PASSWORD 可加在线冒烟

八、常见文件
------------
一键启动.bat        启动 ComfyUI + 网页服务
安全设置.bat        改管理员密码 / 重新生成证书
模型下载.bat        补装模型
修复手机访问.bat    放行 TCP 8800
使用说明.md         完整功能说明
docs/               提示词资料

九、版本锁定
------------
安装器默认使用 installer\versions.lock.json：
ComfyUI v0.42.0、Python 依赖、自定义节点 commit、模型 revision、7zr 哈希
都已锁定；已有 ComfyUI 默认不自动更新。
升级请使用新安装包，并在测试机验证后再发布。
不要随手加 -AllowUpdates，它会脱离版本锁定。
详见 VERSION_LOCK.md。

十、注意
--------
- 服务只监听本机和 192.168.137.1，不会对校园网开放。
- 不要提交 users.json、workers.json、cert.pem、key.pem、models/。
- 模型版权归原模型作者，使用前看模型卡许可。

十二、只卖安装程序的商业清洁模式
--------------------------------
双击“安装_商业版.bat”：
- 不下载画图模型，不装 GPL 自定义节点；
- 中文翻译使用 MIT 兼容层 + Argos CC-BY 4.0 模型，不安装 AGPL 的 MiniSBD；
- 已有 ComfyUI 直接复用，不自动更新；
- 没有 ComfyUI 会询问是否下载；
- 加 -NoTranslate 可完全跳过翻译，只使用英文提示词。
高级参数：-SkipComfyUI / -ComfyUIDir <已有 ComfyUI 目录>。
这样安装包里只有自己的安装器和网页代码，ComfyUI/模型/第三方节点由用户选择。
