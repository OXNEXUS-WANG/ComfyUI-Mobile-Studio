## 激活

商用版绑定机器码，首次打开会跳到 `/license` 页面显示本机机器码。把机器码发给
供应商换取离线授权码，然后粘贴授权码或导入 `license-*.json` 文件即可。

- 授权码只能在本机使用，复制到其他机器会提示「不属于这台机器」。
- 授权到期前可以用新码覆盖激活续期。
- 「后台 → 系统设置 → 商用授权」可以查看客户、到期时间和机器码。
- 商用版主界面显示「商用授权 · 客户 XXX」水印；活动/安全审计日志带客户名和
  机器指纹（机器码哈希前 12 位），方便追踪授权来源，不写授权码原文。
- 激活过程只验证签名和机器码，不上传图片、提示词或账号信息。

## 安装

1. 解压 Setup ZIP 到一个普通文件夹。
2. 双击 `安装.bat`。
3. **首次安装必须先阅读并同意醒目的免责声明与使用协议**：完整阅读后勾选
   “我已阅读并理解上述免责声明”，再点“同意并继续”；不勾选无法继续，
   点“退出安装”不会修改系统。完整文本见 `DISCLAIMER.md`。
   无人值守安装必须显式添加 `-AcceptDisclaimer`，否则安装器拒绝执行。
4. 安装器默认使用 **商业清洁模式**：
   - 不下载画图模型
   - 不安装 GPL 自定义节点
   - 中文翻译使用 MIT 兼容层 + CC-BY 4.0 模型，不安装 AGPL 的 MiniSBD
   - 已有 ComfyUI 直接复用，不自动更新
   - 没有 ComfyUI 时询问是否下载官方便携版
5. 安装完成后，桌面会出现“手机出图”快捷方式。
6. 用户自行安装 ComfyUI、模型和需要的插件；如果加 `-NoTranslate`，
   请使用英文提示词。

如果已经安装 ComfyUI，可以在运行安装器前把 `-ComfyUIDir` 指向该目录，
或直接让安装器检测默认安装目录。

## 主要功能

- 手机网页出图、图库、多账号、限额、日志和 HTTPS
- 商用版默认额度：**50 个启用账号、20 台算力节点**（分享版为 5 / 2）；
  管理员后台会显示已用/上限，满额时自动禁用创建和接入按钮
- 局域网多机算力共享，管理员审批和公平排队
- 中文提示词 Argos 翻译，或接入 Ollama / OpenAI 兼容的本地小模型
- 24 小时游客账号，到期自动禁用
- 配置还原点、一键回滚和系统重置（保留当前管理员和图片）
- 自动磁盘清理（默认关闭）、图库多选打包下载
- 模型管理：浏览器分块上传、服务器路径导入、删除到回收站
- 一键体检报告（HTML + JSON + 脱敏日志 ZIP）
- U 盘离线迁移：模型下载前选择目标机器，一键打包并一键迁移
- 模型家族识别、推荐参数和新手提示

## 系统要求

- Windows 10/11 64 位
- NVIDIA 显卡，建议 8GB 显存以上
- 至少 20GB 空闲磁盘（实际模型占用取决于用户自己下载的模型）
- 手机和电脑连同一个 Windows 热点
